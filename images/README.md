# Images

This directory is reserved for photographs, scans, maps, and other visual records relevant to the archive.

## Image documentation rules

For each image, record when known:

- Original creator or photographer.
- Approximate or exact date.
- Original source or collection.
- Location and subject.
- Rights or permission status.
- Whether the image is original, edited, cropped, or annotated.
- What the image actually demonstrates—and what it does not demonstrate.

Do not remove provenance or imply ownership of images whose rights are unknown. Do not use an undated image to assert a precise historical date without supporting evidence.
