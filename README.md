# Medan Memory Archive

A personal historical archive documenting memories, places, architecture, education, and cultural heritage of Medan, Indonesia.

## Purpose

This repository preserves personal recollections and investigates the historical context of places in Medan. It is not an official institutional history and does not claim that every remembered detail has been independently verified.

## Documentation principles

- **Memory is evidence of recollection, not automatic proof of historical fact.**
- Separate firsthand memories, documented facts, interpretations, hypotheses, and unknowns.
- Do not invent dates, names, sources, architectural details, or historical connections.
- Preserve uncertainty explicitly. UNKNOWN is not ZERO.
- Correct the archive when better evidence becomes available.
- Respect privacy. Do not publish personal information about private individuals without a clear reason and appropriate consent.

## Structure

- `articles/` — narrative articles and historical investigations.
- `sources/` — source notes, references, and verification status.
- `images/` — image documentation and image-use notes.
